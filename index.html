NO SIGN-IN CLAIMS

For Power Automate, myTIME sends your selected timecard payload through a same-origin Cloudflare Pages Function. This avoids browser CORS problems; the flow URL is stored in your signed-in Cloudflare profile and is only forwarded with the request. The receiver is restricted to Microsoft Power Automate / Azure Logic Apps HTTPS hostnames. A Google Apps Script web app or another HTTPS webhook can still be selected as a generic receiver. This webhook connection does not require Google or Microsoft OAuth sign-in.

Security & delivery

The managed Make webhook is stored as a Cloudflare secret; custom webhook URLs are synced to your signed-in Cloudflare profile. Need a webhook receiver?

Power Automate setup: create an Automated cloud flow with the trigger “When an HTTP request is received”. Use the JSON schema below, save the flow to generate its HTTP POST URL, then paste that URL above. Add “Send an email (V2)” for weekly reports and map to to To, subject to Subject, and htmlBody to the email body; enable HTML if your action exposes that option. For other event types, add a condition on event before processing.
