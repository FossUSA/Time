Security & delivery

This static site does not store credentials on a private server. The URL and report options are saved in this browser only. Sending requires your explicit click and confirmation. Browser CORS or receiver settings may block a request; verify the receiving service processed it. Automatic weekly sending and secure company sign-in are not enabled.

Need a webhook receiver?

Power Automate setup: create an Automated cloud flow with the trigger “When an HTTP request is received”. Use the JSON schema below, save the flow to generate its HTTP POST URL, then paste that URL above. Add “Send an email (V2)” for weekly reports and map to to To, subject to Subject, and htmlBody to the email body; enable HTML if your action exposes that option. For other event types, add a condition on event before processing.
